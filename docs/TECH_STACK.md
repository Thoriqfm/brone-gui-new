# TECH STACK

React + TypeScript + Vite + Zustand + Anime.js; FastAPI + Pydantic + WebSocket; Linux Brave kiosk target.

Optional command ingress: Eclipse Mosquitto broker (separate service) and Python `paho-mqtt>=2.1,<3`, using MQTT 3.1.1 and a QoS 1 subscription. No browser MQTT dependency or ROS2 bridge is required.
